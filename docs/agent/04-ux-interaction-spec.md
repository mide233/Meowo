# 04 · UX 与交互规范（UX & Interaction Spec）

- 状态：Baseline
- 版本：v0.1.0
- 最后更新：2026-10-19
- 关联：需求 [01-functional-requirements.md](01-functional-requirements.md)，技术 [02-technical-architecture.md](02-technical-architecture.md)

---

## 1. 体验目标

1. **打开即写**：新建或打开文档后，不经过模式向导即可落笔。
2. **工具可预测**：同一手势在不同工具下有稳定结果；误触可撤销。
3. **层次清楚**：纸张/图书页、内容、批注、工具、面板有明确视觉层级。
4. **手机可用**：复杂能力在窄屏上通过底部工具条与抽屉降级，而不是简单挤压桌面布局。
5. **长期使用不疲劳**：低对比背景、克制动效、足够点击区域、可自定义笔刷与输入方式。
6. **不隐藏关键状态**：保存失败、内容溢出、锁定图层、渲染失败必须有可见反馈。

## 2. 设计语言与设计令牌

### 2.1 方向

- Material Design 3 组件与状态语义。
- 温暖、安静的纸张质感；扁平为主，层级依靠 surface 角色、细描边与轻阴影。
- 品牌强调色：暖琥珀/橘色（临时方向）；猫元素通过图标轮廓、空状态插画和动效细节表达，不铺满 UI。
- 不使用：大面积渐变、玻璃拟态、霓虹色、过多悬浮气泡、手绘字体 UI。

### 2.2 色彩角色（临时基线）

| 角色 | 建议 | 用途 |
|---|---|---|
| `primary` | 暖琥珀橘（M3 seed 派生） | 主要按钮、当前工具、焦点 |
| `onPrimary` | 深棕/近黑 | 主要按钮文字 |
| `surface` | 暖白（浅色）/暖深灰（深色） | 面板、背景 |
| `surfaceContainer` | 略不同于 surface | 工具条、卡片 |
| `outlineVariant` | 低对比暖灰 | 分隔线、未选中描边 |
| `error` | M3 标准错误色 | 保存失败、损坏文件、删除 |
| 纸张色 | 暖白/米白 | 画布纸张 |
| 默认墨色 | 近黑暖灰 | 笔迹、正文 |
| 荧光笔色 | 半透明黄/绿/粉/蓝 | 标注 |

- 使用 M3 `ColorScheme.fromSeed` 派生，再以显式 token 覆盖纸张/墨色。
- 语义色不得只在代码中硬编码；在主题层集中管理。
- 深色模式下纸张不用纯白，文字不用纯黑；避免高亮荧光在深色下刺眼。
- 对比度至少 WCAG 2.2 AA。

### 2.3 字体与排版

- UI：系统 UI 无衬线字体，中文回退到平台 CJK 字体；若为保证三平台一致而打包字体，必须确认体积与 OFL 许可。
- 文档正文：默认可选“无衬线/衬线”字体令牌；1.0 至少提供稳定的默认阅读字体，不要求完整字体选择器。
- 字号阶梯采用 M3 type scale（如 label/body/title/headline），不随意新增字号。
- 行高、段间距统一由设计 token 提供。
- 支持系统字体缩放；在 200% 缩放下关键流程仍可用。

### 2.4 形状、间距、动效

- 圆角：小控件 8–12 dp；卡片 12–16 dp；底部工具条 16–24 dp；遵循 M3 shape scale。
- 间距：4 dp 基准，常用 8/12/16/24。
- 触控目标：最小 44×44 dp，优先 48×48 dp；桌面鼠标目标可更紧凑但不低于 32 dp。
- 图标：Material Symbols Rounded，统一 24 dp 网格，选中态使用 filled 变体。
- 动效：常规 150–250 ms，面板 250–300 ms；避免弹跳过度；遵循减少动态效果。
- 页面切换：淡入/轻微位移，不使用 3D 翻书动画。

### 2.5 画布视觉

- 书页：纸张带 1px 低对比描边和极浅阴影，与背景区分；页面之间不显示额外装饰。
- 无极画布：连续纸张底色铺满视口，不绘制固定页面边框或阴影；空白时仅保留连续底色，横线/点阵/方格按世界坐标锚定并只在可见视口内绘制。缩放很低时纹理逐渐淡出，避免噪点。
- 纸张样式：空白/横线/点阵/方格；线色低对比，不抢笔迹。书页样式保持既有页内绘制方式。
- 图书页：完整显示书页内容，不叠加纸张纹理；周围为中性背景。
- 选中元素：高亮描边 + 角/边控制点，不覆盖内容本身。
- 进行中的笔迹与已提交笔迹视觉一致；不得出现“抬起笔后才变样”。

## 3. 信息架构与导航

### 3.1 顶层结构

```text
应用
├── 资料库（首页）
│   ├── 全部文档
│   ├── 收藏
│   └── 回收站
├── 文档编辑器
│   ├── 无极画布
│   ├── 书页画布
│   └── 喵书籍
└── 设置
    ├── 外观与语言
    ├── 手写笔与输入
    ├── 默认纸张/新建
    ├── 存储与缓存
    └── 关于与许可证
```

### 3.2 自适应导航

| 宽度 | 导航 | 编辑器布局 |
|---|---|---|
| `< 600 dp`（compact，手机） | 底部 `NavigationBar`：资料库、收藏、设置；回收站从资料库菜单进入 | 顶栏 + 画布 + 底部横向工具条；页面/图层/附件使用底部抽屉 |
| `600–1024 dp`（medium，平板竖屏/小窗） | 左侧 `NavigationRail` 或紧凑导航 | 左侧工具轨 + 右侧可收起检查器（页面/图层）；底部上下文工具条 |
| `> 1024 dp`（expanded，桌面/平板横屏） | 完整侧栏 + 顶部标题栏 | 左侧工具轨、右侧检查器面板、顶部上下文工具条；可并排文本编辑/预览 |

- 旋转/调整窗口时保留当前文档、页面、工具与相机；不得跳回资料库。
- 系统返回键/手势：先关闭弹出层/面板，再退出编辑；编辑内容已自动保存，不弹“是否保存”阻断。

## 4. 资料库

### 4.1 布局

- 顶部：应用品牌/标题（桌面）、搜索入口、排序、视图切换。
- 主区：文档卡片网格或列表。
- 新建：右下 FAB（手机）或顶栏主按钮（桌面）；点击直接新建上次默认类型，长按/下拉选择其他类型。
- 文档卡片：
  - 封面缩略图（第一页/初始画布）；
  - 标题（最多 2 行省略）；
  - 类型标识（无极/书页/书籍）；
  - 修改时间；
  - 收藏星标；
  - 溢出菜单（重命名、收藏、复制、导出、删除）。
- 空状态：简短插画 + “新建文档”与“导入 PDF/EPUB”操作。
- 桌面支持右键菜单；触屏支持长按菜单。

### 4.2 新建

“新建”菜单：

1. 新建无极喵文档；
2. 新建书页喵文档；
3. 导入 PDF 创建喵书籍；
4. 导入 EPUB 创建喵书籍；
5. 导入 Markdown（待 OQ-002 确认，未确认不展示为已支持能力）。

流程：

- 新建无极：立即创建并进入，无额外对话框（可后续在编辑器重命名）。
- 新建书页：打开纸张对话框：
  - 预设：A4 / A5 / B5 / Letter / Legal / 自定义；
  - 方向：纵向/横向（分段按钮）；
  - 自定义：宽/高，单位 mm（显示 pt 换算），范围校验；
  - 纸张样式：空白/横线/点阵/方格；
  - 页面预览；
  - 默认值来自设置（默认 A4 纵向、空白）。
- 导入 PDF：文件选择器 → 校验/加密密码（如支持）→ 导入进度 → 成功进入文档或返回资料库。
- 导入 EPUB：文件选择器 → 版面设置（纸张/字号/边距）→ 进度 → 成功。
- 导入失败显示：原因、文件名、重试/取消；不进入资料库。

### 4.3 搜索与筛选

- 搜索框在资料库顶部；输入后 200–300 ms 防抖。
- 搜索范围：标题 + 文本元素，结果按相关度/修改时间排序。
- 结果展示文档标题、类型、匹配片段；点击打开并尽量定位到页面。
- 无结果：显示搜索词与清空操作。
- 收藏筛选：与搜索可组合。
- 排序：最近修改（默认）、创建时间、标题 A→Z。

### 4.4 重命名/删除/回收站

- 重命名：对话框，自动聚焦全选；空白回退“未命名”；确认后保存。
- 删除：移到回收站，Snackbar “已移到回收站” + 撤销。
- 回收站：显示删除时间；恢复/永久删除；永久删除必须确认对话框，明确不可恢复。
- 无回收站权限/文件被占用：显示失败原因，不假装删除成功。

### 4.5 导入/导出入口

- 从 `.meowo` 导入：与打开文件相同，复制进资料库并重新分配 ID。
- 导出：生成 `.meowo` 快照；通过系统保存/分享。
- 无极画布 PNG/PDF 导出：按可见内容包围盒 + 32 pt 留白裁切，不套用旧的 1600×1200 页面；空画布回退到原点附近 1000×700 pt 视口。隐藏图层不导出。导出图像单边限制 4096 px、总量约 1200 万像素；超限时等比降低分辨率而非裁掉内容；PDF 页面单边限制 14400 pt。书页/书籍导出继续按页面尺寸逐页导出。
- 附件/图书源不会在资料库单独显示。

## 5. 编辑器整体布局

### 5.1 组件

```text
┌────────────────────────────────────────────────────────────┐
│ 返回  标题 [编辑]                         保存态 撤销 重做 ⋮ │
├────────────────────────────────────────────────────────────┤
│ 工具上下文栏（颜色/粗细/橡皮模式/文本选项等）              │
├──────┬──────────────────────────────────────────┬──────────┤
│ 工具 │                                          │ 页面/图层面板 │
│ 轨   │                 画布                     │          │
│      │                                          │          │
├──────┴──────────────────────────────────────────┴──────────┤
│ 页面导航（书页） / 当前工具名 / 缩放比例                     │
└────────────────────────────────────────────────────────────┘
```

- 顶栏：返回资料库、可编辑标题、保存状态、撤销/重做、更多。
- 工具轨：选择/套索、手、笔、荧光笔、橡皮、文本、图片、附件；可分组与折叠。
- 上下文栏：随工具变化，避免把全部设置塞进顶栏。
- 检查器：页面缩略图、图层、附件、图书目录按需切换。
- 底部状态：页码、缩放、图层/输入提示。
- 画布占据最大空间；面板可收起，不遮挡正在编辑的区域。

### 5.2 顶栏与保存状态

- 标题行内编辑，失焦/回车提交。
- 保存状态：
  - 已保存：云? 不用云图标；使用“已保存”文字/勾选；
  - 保存中：小型进度；
  - 保存失败：持续可见错误按钮，打开详情与重试。
- 禁止使用“假保存”图标：失败时必须改变状态。
- “更多”菜单：文档信息、导出副本、快捷键帮助、页面/图层管理入口、删除文档。

### 5.3 工具切换

- 点击工具即切换；快捷键（可选）：
  - `V` 选择/套索
  - `H` 手
  - `P` 笔
  - `M` 荧光笔（Marker）
  - `E` 橡皮
  - `T` 文本
  - `I` 图片
  - `A` 附件
- 工具栏只显示图标 + 名称 tooltip；手机使用图标 + 菜单。
- 当前工具有明确 selected 状态；工具设置保留上次值（会话内）。
- 绘制进行中切工具：完成当前笔画后切换，不丢弃笔迹。

## 6. 手写工具

### 6.1 笔

- 默认工具；默认墨色近黑。
- 上下文栏：颜色（最近色板 + 自定义）、粗细、压力曲线入口、更多笔刷预设。
- 压感：默认开启；鼠标/无压感输入使用可配置固定压力/速度模拟。
- 笔刷预设管理在设置/笔刷面板：新建、重命名、删除；至少笔与荧光笔各有默认预设。
- 画布缩放时笔迹视觉粗细按文档坐标缩放，界面显示的“4 pt”保持真实单位。
- 绘制预览使用与最终笔迹一致的透明度、颜色、压力曲线；结束不出现颜色/宽度突变。

### 6.2 荧光笔

- 默认黄色、半透明、较宽；上下文栏可改色/宽/透明度。
- 与笔迹同图层时按元素顺序叠加；提供“荧光笔置于文字下方”的常用预设（通过图层或绘制顺序实现，不自动修改其他元素）。
- 不强制直线；按真实笔迹绘制。
- 高亮区域内文字需可辨；过于不透明时给出视觉提示，不阻止用户。

### 6.3 橡皮

- 点击橡皮打开模式分段：**整笔** / **像素**。
- 上下文栏：尺寸滑块 + 数值；橡皮圆形光标预览（鼠标/支持悬停的笔）。
- 整笔：路径接触即删除整条笔迹；预览高亮将被删除的笔迹。
- 像素：按半径裁切笔迹，实时预览；一次手势撤销恢复全部。
- 擦除只作用于当前可见且未锁定的图层；跨图层可切换“仅当前层/所有可见层”设置（默认仅当前层）。
- 橡皮端（若设备支持）可直接擦除，模式遵循当前设置；与工具状态不冲突。

### 6.4 压力曲线编辑器

- 入口：笔刷上下文栏 → “压力曲线”。
- 二维曲线：横轴输入压力 0–1，纵轴输出宽度/不透明度 0–1。
- 默认曲线为轻压也可见、重压明显加粗；控制点至少 2 个，可拖拽/增删（端点固定 x=0/1）。
- 提供重置默认、取消、保存；保存影响当前预设的新笔迹。
- 预览区域实时显示一条示例笔迹。
- 曲线必须保持 x 单调递增；非法拖拽被限制，不弹复杂错误。

## 7. 选择、套索与对象操作

### 7.1 选择工具

- 工具轨“选择/套索”为组合工具：
  - 点击对象：单选；
  - 拖拽空白：套索选择；
  - Shift 点击：多选（桌面）；触屏可用“添加选择”切换；
  - 点击空白：取消选择。
- 选择范围：当前页、可见且未锁定图层。
- 隐藏图层中的对象不可选中；锁定图层可选显示但不可操作（点击给出提示）。

### 7.2 选择反馈

- 元素显示高亮描边；多选显示共同包围盒。
- 包围盒控制点：
  - 四角：等比缩放（Shift 可切换非等比，桌面）；
  - 四边：单轴缩放；
  - 旋转把手：旋转（Phase 3，若实现受限，图片仍可在图片编辑器中做 90° 旋转）；
  - 移动：拖动选区内部。
- 触屏控制点放大约 32–40 dp 视觉/命中区，避免难以抓取。
- 缩放时显示尺寸/角度辅助信息，可关闭。

### 7.3 操作方式

- 移动：拖拽；箭头键微移 1 pt，Shift+箭头 10 pt。
- 删除：`Delete/Backspace`、上下文按钮；可撤销。
- 复制/粘贴：`Ctrl/Cmd+C/V`、长按/右键菜单；粘贴偏移 16 pt。
- 剪切：Cut = 复制 + 删除，一个撤销单元（桌面）。
- 全选：选择当前页所有可见未锁定对象（桌面 `Ctrl/Cmd+A`，文本框内优先文本全选）。
- 图层移动：右键“移动到图层”；不改变页面坐标。
- 元素顺序：上移一层/下移一层/置顶/置底（层内）。
- 改变颜色/线宽：选中笔迹后通过上下文栏批量修改；样式变更可撤销。
- 文本/图片/附件都可被选择、移动、删除；本底文本只能编辑/选择复制，不随意移动（见 8.4）。

### 7.4 空选择与冲突

- 无选择时，上下文栏显示当前工具设置，不显示对象操作。
- 选择中包含锁定/已删除元素时，自动剔除并提示。
- 选择跨页不支持：切换页面时清空选择。

## 8. 文本编辑

### 8.1 文本工具

点击“文本”后：

- 在画布拖拽创建文本框；
- 点击已有文本进入编辑；
- 上下文栏显示“新建文本框 / 编辑本底文本”入口。

### 8.2 文本框

- 创建时使用当前默认字号；书页中拖拽/默认位置决定初始宽高；无极画布中默认放在当前可见视口中心（宽 360 pt、高 160 pt），不依赖页面宽度。
- 图片与附件在无极画布中同样默认落在当前可见视口中心附近；书页中保持既有落点规则。
- 默认自动高度：宽度改变时重排并增长高度；
- 固定高度：显示高度把手；内容超出时：
  - 编辑态：框内滚动；
  - 非编辑态：显示溢出提示角标/底部渐隐，不得静默丢弃内容；可展开/切换自动高度。
- 双击文本进入编辑；桌面单击即可进入（取决于选择工具）。
- 编辑态显示光标、选择高亮与 Markdown 工具条；画布其他对象仍可见但变暗少许。
- 点击空白/完成按钮/返回提交；`Esc` 取消当前未提交编辑（若已输入则提示或按文本控件撤销策略）。
- 文本元素失焦自动提交为单一撤销单元。

### 8.3 Markdown 编辑与预览

- 编辑界面：
  - 紧凑屏：顶部分段按钮“编辑 / 预览”；预览模式只读显示渲染结果；
  - 宽屏：可切换为并排源码 + 预览；预览实时更新（可短防抖）。
- 工具条包含：粗体、斜体、删除线、标题、列表、任务列表、引用、代码、链接、公式、附件链接。
- Markdown 源码区使用等宽字体；换行、缩进、列表续行行为稳定。
- 预览支持 CommonMark + GFM 子集 + 数学公式；代码块基础高亮。
- 链接点击：
  - HTTP(S)：显示完整目标，确认后使用系统浏览器；
  - `mailto:`：确认后调用邮件应用；
  - `meowo://asset/<id>`：打开附件/图片；
  - 未知协议：提示不支持，不静默调用系统。
- 不允许内联脚本、iframe、远程图片。图片节点加载失败显示替代文本。
- 公式解析失败：显示红色错误占位与原始 TeX，可点击/选择回到源码。

### 8.4 本底文本（Page Body Text）

- 入口：文本上下文栏的“本底文本”或文档创建时的正文模式。
- 书页：
  - 占据页面正文区域（默认四边 48 pt 边距，可在文档/页面设置调整？1.0 采用统一默认，暂不暴露复杂版式）；
  - 默认位于最底层可见图层，可通过图层面板移动归属，但保持页面区域约束；
  - 不可自由移动/旋转；可编辑内容；
  - 内容超过页面可用高度时显示底部溢出指示，编辑态滚动；提示可以增加页或拆分内容（1.0 不自动跨页）。
- 无极：
  - 固定在文档原点，默认阅读宽度 720 pt；
  - 目标高度随内容增长；当前实现使用 1600 pt 高度并显示既有溢出角标，动态测高仍为后续项；
  - 不参与常规选择拖动；通过文本工具直接编辑；可随画布平移/缩放，但不可自由拖动。
- 同一页面最多一个本底文本；重复创建时聚焦现有元素。
- 本底文本仍会进入全文搜索和导出/渲染。

### 8.5 键盘与输入法

- 桌面支持完整文本编辑快捷键；输入法组合区不触发 Markdown 快捷格式干扰。
- 中文输入法候选窗不被画布手势遮挡或强制关闭。
- 字体缩放不导致行高裁切。
- 文本选择可复制到系统剪贴板；从系统粘贴 Markdown/纯文本时保留换行，不执行不可信 HTML。

## 9. 图片

- 图片工具 → 系统文件选择器/拖放/粘贴；

- 插入位置以视口中心或落点为准；

### 9.2 变换

- 选中后显示包围盒；拖拽移动、角点等比缩放、边点单轴缩放、旋转把手。

- 裁剪模式：双击图片或上下文“编辑图片”打开内置编辑器。
- 删除/复制/粘贴遵循通用对象规则。

### 9.3 内置图片编辑器

- 全屏/大尺寸对话框，深色中性背景；
- 工具：裁切、旋转 90°、水平翻转、垂直翻转、重置；
- 裁切：
  - 自由裁切或固定比例（1:1、4:3、16:9、原始比例）；
  - 拖拽裁切框和边/角；显示像素尺寸；
  - 确认才提交，取消不改变原图；
  - 非破坏性：记录裁切矩形与旋转/翻转，不覆盖原资产。
- 图片解码失败：对话框显示错误，保留原元素不变。
- 大图预览使用降采样，确认结果按显示需要重新解码。

### 10.1 导入与放置

- 附件工具 → 文件选择器（可多选）；导入后：

- 图标显示文件名/类型；长文件名中间省略，悬停/长按显示全名；图标大小可缩放，文字保持在可读范围。

### 10.2 Markdown 链接

### 10.3 附件文件夹

- 分区：附件 / 图片 / 图书源（只读，提示不应删除）；

- 操作：打开/预览、在画布定位引用、导出、删除；
- 删除被引用附件：对话框列出引用数并说明将删除画布/文本引用（或禁止删除，推荐先移除引用）；1.0 选择“确认删除并移除引用”或“取消”，绝不静默留下断链；
- 空状态解释“导入附件后显示在这里”。

### 10.4 打开方式

- 默认系统查看器/关联应用；应用内可提供图片/PDF 预览（后续）。
- 可执行文件不自动运行；提示用户确认系统打开。
- Android 通过 FileProvider/临时文件安全共享；不暴露资料库路径。

## 12. 页面与纸张

### 12.1 页面导航

- 书页文档：
  - 底部状态栏/页面面板显示“第 N / 总页数”与上一页/下一页；
  - “第 N / 总页数”可点击，打开页面卡片选择器（轻量卡片，非实时缩略图），当前页高亮，点击跳转；
  - 缩略图面板支持跳转、添加、复制、删除、重排；
  - `PageUp/PageDown` 翻页（无文本焦点时）。
- 水平翻页手势（书页与喵书籍）：
  - 仅在“适合页面”缩放（zoom≈1.0）时启用；无极画布不启用；
  - 页面外灰色边缘起手的清晰水平快速滑动可用任意工具翻页，不会开始绘制；
  - 页面内起手仅“移动”工具支持清晰水平快速滑动翻页，普通/短距/斜向拖动仍平移；
  - 水平位移需占主导且达到距离/速度阈值；双指手势、笔输入、鼠标中键不参与翻页；
  - 翻页使用约 240 ms 的横向滑入/滑出 + 淡入过渡，不使用 3D 翻书动画。
- 无极画布：不显示上一页/下一页、页码选择器或插入/删除页；底部只显示“无极画布”和逻辑范围提示。无极文档始终只有一张画布页，页面导航不适用。
- 纸张尺寸创建后不可编辑；文档信息中显示 A4 纵向等信息。
- 页面缩略图异步生成，占位淡灰；失败显示通用页图标。
- 添加页默认插入当前页之后；删除当前页后跳转到相邻页；最后一页禁止删除（至少保留一页）。

### 12.2 相机

- 打开书页默认“适合页面”，留出边距；用户缩放/平移后保留当前页相机；切页按文档级相机策略：
  - 1.0 默认：切页使用“适合页面”，除非用户开启“保持缩放比例”；
  - 缩略图跳转同样遵循。
- `适合页面`/`适合宽度`/`100%` 在菜单和快捷键中提供；书页/书籍保留“适应页面”。
- 无极画布相机：
  - 逻辑范围约 ±100,000 pt，文档原点为 `(0, 0)`；画布可为负坐标与远距离坐标，不绘制固定页面框。
  - 打开时若存在可见内容，自动“适应内容”；空白画布将原点放在视口左上附近（屏幕 64,64），缩放 100%。
  - 工具轨提供“回到原点”（100% 缩放、原点回到左上附近）与“适应内容”（带 48 pt 屏幕边距）；书页/书籍只保留“适应页面”。
  - 平移被限制在逻辑范围内：视口不能整体移出 ±100,000 pt；缩放范围 10%–800%。
  - 鼠标滚轮以指针为中心缩放；双指平移/缩放、移动工具、鼠标中键临时平移均可用；不启用页面滑动翻页。
  - 1.0 当前实现不跨重启保存无极相机位置。
- 不给缩放加过于敏感的惯性；以内容跟随手指为准。

## 13. 喵书籍阅读与批注

### 13.1 打开/渲染

- 打开书籍优先显示第一页/上次阅读页与缩略图骨架；
- 页面背景渲染期间仍可翻页、缩放、切换工具；批注层不被阻塞；
- 渲染失败显示单页错误占位与“重试”；
- 图书页只读：尝试选择/移动背景时显示提示；无背景元素可编辑。

### 13.2 阅读控件

- 页面导航、跳转输入、目录（若可用）、适合页面；
- 图书信息：标题、格式、页数、导入时间、引擎信息（诊断/details）。
- 不显示 PDF 源原文件字体/解析错误长文本；仅提供可读说明与技术详情入口。

### 13.3 批注

- 默认新图层“批注 1”或使用当前活动图层；书籍导入后自动创建默认批注图层，位于背景之上。
- 笔、荧光笔、文本、图片、附件均可用于批注；
- 1.0 不修改原页面；不支持在源页上直接“打字填空”。
- 目录跳转后显示当前页码。
- 书籍页面无法新增/删除/重排；关闭文档再打开，页码与批注一致。

### 13.4 导入设置

- 所有格式导入在后台 isolate 执行；导入期间显示不可关闭的不确定进度层并禁用导入按钮，防止重复导入。
- 成功时刷新资料库并打开新文档；失败时关闭进度层、保留原资料库并显示可读错误；核心未上报确定进度，不显示虚假百分比。
- PDF：文件、密码（如适用）、导入进度；不修改 PDF。
- EPUB：
  - 纸张尺寸/方向；
  - 基础字号；
  - 边距/版心（至少提供默认/紧凑/宽松）；
  - 预览前几页（若引擎允许）与页数估计；
  - 说明导入后会固定分页，之后不能改变排版；批注与固定页绑定。
- DRM 或不支持格式：明确错误，不重试无效解析。

## 14. 设置

分组：

1. **外观**
   - 主题：系统/浅色/深色；
   - 语言：系统/简体中文/English；
   - 减少动态效果（若平台未提供覆盖）。

   - 输入模式：自动/仅手写笔/手写笔与手指（按决策 D-015）；
   - 压感：开启/固定压力，固定压力值；

   - 压力曲线管理；
   - 笔尖橡皮行为；
   - 橡皮默认作用范围（当前图层/所有可见图层）。

5. **关于**

   - 导出诊断信息（不含用户内容/密码）。

## 15. 输入矩阵

### 15.1 默认行为

| 输入 | 手机（默认） | 平板/桌面（默认） | 说明 |

| 双指触摸 | 平移/捏合缩放 | 平移/捏合缩放 | 始终可用（文本编辑区域除外） |

| 鼠标中键/空格+左键拖 | 平移 | 平移 | 桌面 |
| 鼠标滚轮 | 垂直平移 | 垂直平移；Shift 水平；Ctrl/Cmd 缩放 | 桌面 |
| 触控板捏合 | — | 缩放 | 桌面 |
| 笔橡皮端 | 擦除（若识别） | 擦除（若识别） | 可设置 |

### 15.2 手势仲裁

- 绘制工具下，笔/鼠标/允许的手指进行绘制，直到满足两指手势条件；两指按下时若已开始一笔，1.0 采用：
  - 已产生的单笔在第二指出现时结束并以当前点封笔，随后进入缩放/平移；或
  - 在开始绘制后的极短窗口内取消该笔。
  - 具体采用“结束当前笔 + 进入手势”以避免丢失内容；由实现确保不出现跨越手势的意外长线。
- 笔尖接触屏幕期间忽略其他触摸点（手掌/手指），防止误画/跳转。
- 笔离开后短时间内的触摸可进入正常平移；两指手势可随时开始。
- 文本编辑时，单指用于光标/选择，双指行为由文本控件决定；不强制画布平移。
- 工具栏/面板区域的触摸不传递到画布。
- 笔悬停在支持设备上显示橡皮/笔光标；鼠标同理。

### 15.3 桌面键盘快捷键（基线）

| 操作 | 快捷键 |
|---|---|

| 复制/剪切/粘贴 | `Ctrl/Cmd+C/X/V` |
| 删除 | `Delete` / `Backspace` |
| 全选 | `Ctrl/Cmd+A`（文本内为文本全选） |
| 手/选择/笔/荧光/橡皮/文本 | `H/V/P/M/E/T`（若与文本输入冲突则仅在画布焦点生效） |

| 保存状态 | 无需手动保存；可提供 `Ctrl/Cmd+S` 立即 flush 并提示已保存 |

所有快捷键集中定义，支持本地化提示；不劫持文本输入。

## 16. 反馈、错误与状态

### 16.1 非阻塞优先

- 保存、索引、缩略图、图书页渲染失败：优先使用内联状态/Banner，不弹模态框打断书写。
- 导入/导出：模态进度可取消；完成 Snackbar；失败对话框含原因与重试。
- 撤销操作：Snackbar 提供“撤销”，只用于可撤销操作（删除文档进回收站等）。
- 网络不参与核心流程；离线提示仅在用户明确执行网络操作时出现（1.0 无网络操作）。

### 16.2 错误文案

- 面向用户：发生了什么、哪些内容安全、下一步能做什么。
- 不展示堆栈/数据库 SQL/英文底层异常；技术详情可复制。
- 文档损坏/版本过新：说明是否只读、如何导出诊断、不会覆盖原文件。
- 图层锁定：说明“当前图层已锁定，解锁或切换图层后可绘制”。

### 16.3 空状态

- 资料库：品牌插画 + 两个主操作。
- 搜索：搜索词 + 清空。
- 图层/页面/附件：简短说明与创建入口。
- 书籍目录为空：显示“此文件没有可用目录”，仍可翻页。

## 17. 无障碍、本地化与适配

### 17.1 无障碍

- 所有图标按钮有语义标签和状态（已选中/已锁定/已收藏）。
- 焦点顺序：顶栏 → 上下文栏 → 画布 → 面板；弹出层焦点陷阱正确。
- 画布支持屏幕阅读器“文档摘要”：
  - 页面/画布名称、页码、图层列表；
  - 文本元素可读内容；
  - 图片替代文本（用户可在图片属性编辑，1.0 SHOULD）；
  - 附件名；
  - 不逐点朗读笔迹。
- 选择与移动元素提供键盘替代操作（SDK 限制处至少可编辑/删除）。
- 色彩非唯一信息载体；可见/锁定状态配图标/文字。
- 触控目标与间距满足规范；文本缩放 200% 可用。
- 动效可关闭；避免持续动画干扰。

### 17.2 本地化

- 中文（简体）与英文均完整；不出现未翻译的第三方组件文案。
- 日期、数字、文件大小使用本地格式。
- 不通过字符串拼接构造句子；使用 ICU/ARB 占位符。
- 中文长标题、英文长单词在按钮/卡片中正确换行/省略。
- 用户内容不翻译；Markdown 语法不随语言改变。

### 17.3 设备适配

- 横竖屏切换保留编辑状态和相机；软键盘弹出时文本区滚动可见。
- Windows/Linux 高 DPI 下画笔光标、控制点、线宽视觉尺寸正确。
- 桌面最小窗口尺寸由 Phase 0 决定；低于阈值显示可用窄屏布局而非截断。
- Android 返回手势、分屏/自由窗口：自动保存，不丢当前编辑。

## 18. 视觉验收（关键页面）

- 资料库：首屏在手机/平板/桌面均无溢出；空状态和卡片层级清晰。
- 编辑器：画布不小于可用区域的合理比例；面板收起后工具仍可达。
- 笔工具：选中态、颜色/宽度、撤销重做、保存状态在同一视野内可找到。
- 图层面板：可见/锁定/排序一眼可辨，不依赖 hover。
- 文本：源码/预览切换明确，公式/代码/表格在窄屏可横向滚动而不破坏画布。
- 书籍：加载骨架不造成页面跳动；批注在背景未加载时仍可见。
- 深色模式：纸张、荧光笔、选中态和错误态均清晰，无纯白闪光。
- 200% 字体与无障碍检查通过。
