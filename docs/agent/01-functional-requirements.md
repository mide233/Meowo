## 0. 阅读与编号规则

- `MUST`：1.0 必须满足；没有完成即不能发布 1.0。
- `SHOULD`：1.0 应满足；若因明确原因延期，必须记录并得到负责人同意。
- `MAY`：可选或候选，不计入 1.0 验收。
- `Phase` 表示首次计划实现的路线图阶段，不表示优先级降低。
- 每个实现任务必须引用至少一个需求 ID；PR/交付说明必须列出覆盖的 ID。
- 未列为需求的“增强功能”不得喧宾夺主。任何新增范围先更新本文档。

> 术语见 [00-product-charter.md](00-product-charter.md)。数据模型与持久化细节见 [03-document-format.md](03-document-format.md)。交互细节见 [04-ux-interaction-spec.md](04-ux-interaction-spec.md)。

### 1.1 关键验收

- 断网启动、创建、书写、关闭、重新打开全部成功。
- 回收站恢复的文档保持原有缩略图、内容、收藏状态。
- 搜索能命中文本元素中的中英文内容；手写笔迹不被错误宣称可搜索。
- 导出副本在另一台目标平台机器上能打开，附件与图书页内容完整。

| INK-001 | 使用手写笔/触控笔绘制时支持压感；压感影响笔画宽度（默认）并遵守当前笔刷压力曲线。 | MUST | 2 |
| INK-002 | 笔迹以矢量中心线 + 压力采样 + 笔刷参数持久化，不以位图作为主要存储形式。 | MUST | 2 |

| INK-004 | 至少提供钢笔/圆珠笔类不透明笔刷与荧光笔；荧光笔半透明、可叠加且不遮挡文字辨识。 | MUST | 2 |
| INK-005 | 支持编辑笔刷压力曲线（控制点增删/拖动/重置），并在书写预览中立即生效；曲线可按笔刷预设保存。 | MUST | 3 |
| INK-006 | 笔刷预设包含颜色、宽度、透明度、混合模式与压力曲线；可新建、重命名、删除自定义预设。 | SHOULD | 3 |
| INK-007 | 笔迹平滑算法必须保留书写细节；不得产生明显折线、抖动或滞后。算法版本需随数据记录以保持可复现。 | MUST | 2 |

| INK-009 | 荧光笔与普通笔迹可位于不同图层并正确合成；图层透明度与元素透明度相乘。 | MUST | 3 |
| INK-010 | 笔迹颜色、粗细修改作用于当前工具的新笔迹；对选中笔迹的批量改色/改宽作为选择工具操作（见 SEL）。 | MUST | 3 |
| INK-011 | 书写时支持预测事件/前端预览，不因后端持久化或几何提交造成可见断笔。 | SHOULD | 2 |

### 4.1 笔迹质量验收

- 快速画圆、长直线、小字、连笔、轻压/重压均可辨识，压力变化连续。
- 同一笔迹在 50% 与 800% 缩放下保持矢量清晰，不出锯齿块。
- 关闭重开文档后笔迹宽度、压力效果、颜色、图层位置完全一致。
- 在低端 Android 平板上，笔尖到显示反馈的目标 P95 小于 50 ms（设备与测试方法见测试策略）。

## 5. 橡皮、选择与对象操作

| ID | 需求 | 优先级 | Phase |
|---|---|---|---|
| SEL-001 | 提供“整笔擦除”：擦除路径接触到的笔迹元素整体删除；一次手势为一次撤销单元。 | MUST | 2 |
| SEL-002 | 提供“像素擦除”：按擦除半径裁切矢量笔迹，分割为剩余片段；不得把受影响笔迹整体转成位图。 | MUST | 3 |
| SEL-003 | 擦除工具支持可调半径/尺寸、实时预览；隐藏/锁定图层上的笔迹不可擦除。 | MUST | 2/3 |
| SEL-004 | 套索选择支持对笔迹、图片、文本、附件图标进行选择；选择反馈清晰可辨。 | MUST | 3 |
| SEL-005 | 选择对象支持移动、缩放、删除、复制、粘贴；缩放围绕选区中心/控制点进行，行为在 UX 规范中定义。 | MUST | 3 |
| SEL-006 | 支持框选/点击多选（桌面 Shift/Ctrl，触屏通过套索或选择模式）；多选可统一移动/删除。 | SHOULD | 3 |
| SEL-007 | 复制粘贴使用应用内部剪贴板，保留元素样式、图层归属（同文档）与相对位置；文本仍可复制到系统剪贴板。 | MUST | 3 |
| SEL-008 | 对文本、图片等对象提供旋转（至少 90° 步进或自由旋转）与等比/非等比缩放；具体能力见 UX 规范。 | SHOULD | 3 |
| SEL-009 | 选择操作和元素修改支持撤销/重做；一次拖拽、缩放或粘贴为单个撤销单元。 | MUST | 3 |
| SEL-010 | 删除元素后不留下无效引用；若删除附件资产，必须提示会破坏的链接。 | MUST | 3 |
| SEL-011 | 选择跨页/跨图层时规则明确；1.0 至少支持当前页内跨可见未锁定图层选择。 | MUST | 3 |
| SEL-012 | 提供全选当前图层/当前页对象、取消选择、复制、剪切、粘贴、删除的键盘操作。 | SHOULD | 5 |

### 5.1 像素擦除定义

像素擦除通过擦除笔迹路径与矢量笔迹中心线的几何求交实现。接触擦除区域的笔迹被分割为保留段；每段保留原压力采样与笔刷参数。擦除完成后：
- 整段被覆盖的笔迹消失；
- 保持未接触部分形状与端点平滑；
- 撤销一次擦除手势恢复擦除前所有片段；
- 不生成像素蒙版作为持久内容。

## 6. 文本、Markdown 与 LaTeX

| ID | 需求 | 优先级 | Phase |
|---|---|---|---|
| TXT-001 | 文本内容以 UTF-8 Markdown 源文本为唯一事实源；支持 CommonMark 与 GFM 的表格、任务列表、删除线、自动链接。 | MUST | 3 |
| TXT-002 | 支持 LaTeX 数学公式：行内 `$...$`、块级 `$$...$$`，并支持常见 `\(...\)`/`\[...\]` 分隔形式；无法解析时显示可编辑的错误占位，不崩溃。 | MUST | 3 |
| TXT-003 | 支持文本框：用户可在画布/书页任意位置创建、定位、调整宽度与高度；文本按框宽重排。 | MUST | 3 |
| TXT-004 | 支持画布本底文本：书页文档中占据页面正文区域、默认位于最底图层的文本元素；无极文档中为锚定文档原点、固定宽度、纵向自动增长的文本栏。 | MUST | 3 |
| TXT-005 | 文本框默认高度随内容自动增长；用户可切换为固定高度，固定高度超出内容时在编辑态滚动，在非编辑态显示明确的溢出提示（不得静默永久裁切内容）。 | MUST | 3 |
| TXT-006 | 文本编辑提供源码编辑与渲染预览两种显示；桌面可并排，移动端可切换；非编辑状态默认渲染预览。 | MUST | 3 |
| TXT-007 | 文本编辑支持选择、剪切、复制、粘贴、撤销/重做、输入法组合文本（IME）、外部键盘快捷键。 | MUST | 3 |
| TXT-008 | 提供常用 Markdown 快捷操作（粗体、斜体、删除线、标题、列表、引用、代码、链接、公式）；快捷操作必须可键盘触发。 | SHOULD | 3 |
| TXT-009 | 代码块支持等宽显示与基本语法高亮；未知语言降级为等宽文本。 | SHOULD | 3 |
| TXT-010 | 支持链接：HTTP(S)、mailto 与内部附件链接；外部 URL 打开前显示目标并需用户确认（设置可关闭确认）。 | MUST | 3 |
| TXT-011 | 支持在 Markdown 中插入文档内图片资产（作为图片节点）；图片缺失时显示替代文本与占位。 | SHOULD | 3 |
| TXT-012 | Markdown 中的原始 HTML 不得执行脚本；不在白名单内的标签按纯文本/安全降级处理；禁止网络请求加载远程图片（1.0）。 | MUST | 3 |
| TXT-013 | 文本可放置在任意未锁定图层；画布本底文本不自动跨页分页，超出页面时按 TXT-005 处理。 | MUST | 3 |
| TXT-014 | 文本元素支持字号、行高、对齐等基础排版设置；这些设置不改变 Markdown 源文本。 | SHOULD | 3 |
| TXT-015 | 文本编辑提交/失焦时，内容变更为一个可撤销单元；未提交的编辑不写入数据库。 | MUST | 3 |
| TXT-016 | 渲染 Markdown 的阅读视图可用于所有文本元素，支持选择/复制渲染后的文字。 | MUST | 3 |
| TXT-017 | 支持导入独立 `.md` 文件作为新文档或作为文本内容（形式待决策 OQ-002）；未确认前仅承诺笔记内 Markdown 阅读。 | MAY | 待定 |

### 6.1 Markdown 支持边界

1.0 明确包含：

- CommonMark 块级/行内语法基础；
- GFM 表格、任务列表、删除线、自动链接；
- 围栏代码块与缩进代码块；
- 数学公式扩展；
- 引用、列表嵌套、链接、图片、分隔线；
- 脚注、定义列表、HTML 嵌入等扩展不承诺，按安全降级处理。

文本颜色、背景色等富文本属性不在 Markdown 中扩展；使用文字颜色/字号等元素级排版设置（TXT-014）实现。

### 10.1 图书引擎约束

- 必须通过抽象 `BookEngine` 接口访问，不允许业务代码直接耦合 PDFium/MuPDF 等具体库。
- 引擎必须能报告格式、元数据、页数、页面尺寸、目录、渲染一页和取消任务。
- 引擎许可证必须与项目许可证兼容；在许可证决策完成前（OQ-001），不得将 EPUB 引擎并入主线二进制。
- PDF 首选宽松许可证方案（当前建议 PDFium）；EPUB 路线待定。

## 15. 明确不在 1.0 的需求

以下不是遗漏，而是范围控制。若用户提出，先写决策，不直接实现：

- 云同步、账号、团队空间；
- 实时协作、评论、共享链接；
- 手写 OCR 与全文手写搜索；
- AI 功能；
- 音频录制/播放；
- PDF 文本编辑、PDF 表单、PDF 文本重排；
- EPUB 动态重排阅读与导入后改变分页；
- iOS/macOS/Web；
- 无限画布与书页转换；
- 文档模板市场、插件系统；
- 多窗口同时编辑；
- 富文本颜色/字体段落格式（超出 Markdown + 元素级排版设置）；
- 标签、嵌套文件夹、智能分类；
- 云字体或在线图片。

## 16. 可追踪验收场景（端到端）

这些场景在 Phase 5 必须自动化或按人工清单验证：

1. **新用户手写**：断网启动 → 新建无极文档 → 用笔写两段不同压力笔迹 → 切荧光笔标记 → 撤销/重做 → 关闭重开 → 内容与压力一致。
2. **书页编辑**：新建 A5 横向文档 → 插入图片并裁切 → 添加文本框写 Markdown + 公式 → 新建图层并画批注 → 重排页面 → 保存重开。
3. **擦除与选择**：像素擦除跨笔画 → 套索选中多个元素 → 移动、缩放、复制、粘贴、删除 → 逐步撤销回到初始状态。
4. **附件闭环**：导入 PDF 附件并在 Markdown 中链接 → 在附件文件夹打开 → 导出到本地 → 删除引用 → 不存在悬挂引用。
5. **喵书籍**：导入 PDF → 翻页 → 在页面加笔迹和文本 → 切图层显隐 → 关闭重开 → 所有标注位置一致。
6. **EPUB**：导入 EPUB → 目录跳转 → 翻页 → 标注 → 重开 → 页面分页与标注一致。
7. **故障恢复**：编辑中强制结束进程 → 重启 → 文档可打开，最近已保存内容保留；模拟磁盘满/损坏文件不破坏原文档。
8. **无障碍**：开启屏幕阅读器完成打开文档、切换页、编辑文本、管理附件；键盘完成核心桌面流程。
9. **跨平台**：在三平台分别创建/编辑/导出/打开同一文档，验证内容和图层几何一致。

## 17. 需求变更流程

1. 提出变更：说明用户价值、影响的需求 ID、数据格式/架构影响、替代方案。
2. 分类：修复缺陷、澄清现有需求、新功能、范围移除。
3. 批准：新功能或范围移除必须由项目负责人确认；Agent 不得自行批准。
4. 更新：修改本文档、决策记录、路线图、测试计划与任务计划。
5. 实施：按新的验收标准编码与测试。
6. 记录：在计划的变更日志中注明日期与原因。
