## 目标

1. 书页/喵书籍支持水平滑动翻页，带平滑过渡；不影响笔、双指缩放、移动工具、中键平移。
2. 底部“第 X / Y 页”可点击，打开页面卡片选择器并跳转；无极画布不提供。
3. PDF/EPUB/Markdown 导入期间显示不可关闭的进度层，禁止重复导入，正确刷新并打开结果。

## 非目标

- 不实现全屏缩略图渲染、页面重排 UI、章节导航。
- 不实现 PDF/EPUB 导入确定进度（核心未上报进度）。
- 不为无极文档添加翻页。
- 不改变 `.meowo` 文件格式、核心 ABI 或导入管线。

## 交互设计

- 翻页仅在页面处于适合页面缩放（zoom≈1.0）时启用。
- 页面外灰色边缘起手的清晰水平快速滑动：任意工具均可翻页，不进入绘制。
- 页面内起手：仅“移动”工具支持清晰水平快速滑动翻页；普通拖动仍平移，短距离/斜向拖动不翻页。
- 阈值：水平位移占主导、距离足够且速度足够；双指手势、笔输入、鼠标中键不参与翻页。
- 翻页动画：当前页向左/右滑出，新页从另一侧滑入并淡入，约 240 ms。
- 页码选择器使用轻量页面卡片（不宣称实时缩略图），当前页高亮，点击跳转。

## 风险与回滚

- 手势阈值可能误触：通过“适合页面 + 明确快速水平滑动 + 边缘/移动工具”三重限制；出问题可移除 `onPageSwipe` 回调恢复原行为。
- 页面过渡期间保留上一页图片（最多两页）以显示书籍源页；下一次加载自动修剪。
- 导入失败不写入文档；状态在 `finally` 中复位。
