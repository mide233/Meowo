## 1. 目标

在不破坏现有 Alpha 数据与交互的前提下，补齐三个最影响手写体验的核心能力：

1. **矢量像素擦除**：按笔迹几何切分，而不是整笔删除；一次擦除手势只产生一个撤销单元。
2. **压感曲线**：笔与荧光笔分别保存曲线，可编辑控制点、实时预览、重置；渲染与导出使用同一曲线。
3. **套索选择**：自由套索 + 矩形；当前页可见未锁定图层；支持移动、缩放、删除、复制/粘贴；选择框带缩放手柄。

## 2. 非目标（本轮不做）

- 旋转手柄与自由旋转（记录为后续 HC-2）。
- 跨文档复制/粘贴（内部剪贴板仅当前文档）。
- 对象分组、对齐、分布、翻转。
- 文本对象的等比/非等比缩放语义打磨（本轮只做基础框缩放）。
- 性能基准真机数据；不伪造 P95 数字。

## 3. 设计

### 3.1 新文件 `apps/meowo/lib/ink_ops.dart`

纯函数，便于单元测试：

- `defaultPressureCurve()` / `normalizePressureCurve()`
- `applyPressureCurve(double pressure, List<List<num>>? curve)`
- `elementBounds(Map element)`
- `pointInPolygon(Offset point, List<Offset> polygon)`
- `rectIntersectsPolygon(Rect rect, List<Offset> polygon)`
- `splitStroke(Map stroke, Offset point, double radius)` → 切分后的 stroke 列表
- `translateElement(Map element, Offset delta)`
- `scaleElement(Map source, Map target, Rect from, Rect to)`（原地修改 target）

### 3.2 像素擦除

- 橡皮半径 = `max(stroke.width / 2 + 8, 12)` 文档坐标点。
- 对每条受影响笔迹按点采样；把落在圆内的点删除并切分为连续段；保留颜色、宽度、透明度、highlighter、压力值。
- 不足 2 个点但仍有单点的段保留为点。
- 一次 pointer down→up 期间只 push 一次 undo。
- 橡皮模式：像素/整笔；范围：当前图层/所有可见未锁定图层。
- Canvas 新增 `onEraseStart` / `onEraseEnd`，确保手势级撤销。

### 3.3 压感曲线

- 文档 JSON 增加：
  ```json
  "brushSettings": {
    "pen": {"curve": [[0,0],[0.25,0.25],[0.5,0.5],[0.75,0.75],[1,1]]},
    "highlighter": {"curve": [[0,0],[0.25,0.2],[0.5,0.45],[0.75,0.75],[1,1]]}
  }
  ```
- 曲线控制点 x 固定为 0、0.25、0.5、0.75、1，y 可拖动；端点 y 固定在 0/1。
- 渲染时 `pressure -> curve -> width factor`；笔与荧光笔分别取曲线。
- 导出 PNG/PDF 使用同一渲染器，因此自动一致。
- 曲线编辑器对话框：网格、实时预览、重置、取消/应用。

### 3.4 套索选择

- 选择工具下：
  - 空白处拖动：自由套索（默认）或矩形（可切换）。
  - 选择框内部拖动：移动。
  - 四角手柄拖动：缩放。
- 选择范围：当前页所有 `visible && !locked` 图层中的元素；元素自身 `locked` 跳过。
- 选择判定：
  - 自由套索：元素包围盒与多边形相交（默认 intersect）。
  - 矩形：包围盒相交。
- 选择状态只存元素 ID；真实元素仍在各图层内。
- 移动/缩放开始前快照选中元素；每次移动/缩放从快照重算，避免累积误差。
- 复制：深拷贝选中元素到编辑器内部剪贴板；粘贴到当前活动图层，生成新 ID；同一页粘贴偏移 12pt，跨页保持坐标。
- 删除：从所属图层移除；一次操作一个 undo。
- 选择框绘制：虚线边框 + 四角方块；自由套索绘制半透明路径。

## 4. 交互与 UI

- 工具栏“选择”保留；选择状态出现底部浮动条：复制、粘贴、删除、取消、套索/矩形切换。
- 橡皮选中时顶部出现模式菜单：像素/整笔、当前图层/所有可见图层。
- 笔/荧光笔选中时工具栏出现“压感曲线”按钮。
- 选择状态下的缩放不改变页面纸张或图层顺序。

## 6. 风险

| 风险 | 处理 |
|---|---|
| 像素擦除切分产生大量碎片 | 限制每笔最多 64 段；超出则退化为整笔删除并提示 |
| 选择缩放破坏文本布局 | 文本字号按面积平方根缩放并 clamp；本轮不承诺排版级缩放 |
| 手势冲突（选择/绘制/平移） | 仅 `select` 工具拦截；两指缩放仍由外层处理（当前 Alpha 尚未实现画布缩放，记录） |
| 撤销内存 | 继续使用整文档 JSON 快照；本轮不扩大深度 |
| 导出与屏幕不一致 | 共用 `MeowoCanvasPainter` |
