# 计划：无极画布真正无界化（Infinite Canvas）

- 状态：Completed
- 阶段：1.0 编辑器画布
- 负责人/Agent：subagent（OpenCode / DeepSeek V4.1 Flash）
- 创建日期：2026-10-20
- 最后更新：2026-10-20
- 关联需求：`12-final-1.0-baseline.md` §3.1/§3.2/§9；`04-ux-interaction-spec.md` §2.5/§5.1/§8.2/§8.4/§12.1/§12.2
- 关联决策：Q-038（逻辑范围约 ±100,000 pt；原点左上；回到原点/适应内容；不做小地图/固定页面框）
- 关联风险：大坐标精度、导出分辨率上限、无极 `page_body` 动态测高、真机手势验收

## 1. 目标

1. 无极文档使用“视口大小”画布，而不是随固定页尺寸放大的 `SizedBox/CustomPaint`；平移/缩放可越过旧的 1600×1200 页面矩形。
2. 世界坐标经 `_offset`/`_zoom` 映射；逻辑边界约 ±100,000 pt，平移只在边界处夹取；原点保持 `(0, 0)`。
3. 无极背景为连续纸张色；横线/点阵/方格在屏幕/视口空间绘制并裁剪到可见区域，不绘制固定页面边框；书页/书籍纸张背景不变。
4. 无极初始视图：有内容时适应内容，空画布回到原点附近；工具轨提供“回到原点”“适应内容”，书页/书籍继续提供“适应页面”。
5. 笔迹、荧光笔、文本、图片、附件在负坐标/远坐标下继续渲染、命中、选择、变换、擦除与编辑；无极文本框创建于当前视口中心。
6. 无极 PNG/PDF 导出按内容包围盒 + 留白裁切，空画布使用明确回退视口；不静默裁切内容。
7. 保留既有缩放/平移输入：鼠标滚轮指针缩放、双指、移动工具、中键临时平移；不改变笔/触摸绘制。
8. 书页/书籍的页面栏、翻页、页码选择器与“适应页面”保持原行为。

## 2. 非目标

- 不改变 `.meowo` 数据格式、核心 C++、FFI/ABI、MuPDF 导入与附件面板。
- 不实现小地图、固定页面框、画布旋转、相机跨会话持久化。
- 不实现无极 `page_body` 动态测高；本次仍使用固定高度与既有溢出提示。
- 不提供完整矢量场景裁剪/空间索引；仅对画布背景做视口裁剪，元素只做保守可见性跳过。
- 不新增无限画布缩略图/页面选择器。

## 3. 背景与现状

改造前 `CanvasView` 把页面宽度/高度乘以 fit zoom 作为 `Positioned` + `CustomPaint` 尺寸；无极页仍由核心创建为 1600×1200，导致 UI 虽显示“无极画布”，实际只在有限页矩形内绘制，页面外无法落笔，也没有回到原点/适应内容入口。导出同样使用页面宽高。

## 4. 方案

### 4.1 视口与坐标

- 无极分支返回视口尺寸的 `CustomPaint`；painter 内先铺满屏幕空间纸张背景，再 `translate(viewOffset)` + `scale(zoom)` 进入世界坐标。
- `CanvasViewState` 公开只读查询（`scale`、`viewOffset`、`visibleWorldRect`、`worldToScreen`/`screenToWorld`）以及 `resetToOrigin()`、`fitContent()`，供编辑器和测试使用。
- 平移在 `_panBy`、滚轮缩放、双指手势、初始 fit 后统一调用边界夹取：视口可见世界矩形不越出 `kInfiniteCanvasBounds`（±100,000 pt）。缩放范围 10%–800%。

### 4.2 背景与元素

- 无极背景：连续 `#FFFCF5`；按文档/页面背景绘制横线（28 pt）、方格/点阵（24 pt），锚定世界原点、屏幕空间描线，并随缩放淡出；不绘制页面边框/阴影。
- 书页/书籍继续走原有页矩形、纸张纹理、源页贴图与阴影路径。
- 所有元素使用同一世界变换；无极 painter 对可见区域外的元素做保守跳过（按元素包围盒 + 最大边余量，兼容旋转/文本溢出）。
- 命中测试：无极把屏幕点转成世界坐标；书页继续使用页局部坐标。选择、缩放、移动、橡皮均沿用世界坐标差量。

### 4.3 编辑器入口

- 工具栏“回到原点/适应内容”直接调用 `CanvasViewState`；书页/书籍仍用 `viewResetToken` 触发“适应页面”。
- 无极文本框、图片、附件默认放在当前可见视口中心（文本框宽 360、高 160）；`page_body` 仍固定在原点附近（x/y=48，宽 720），不参与选择拖动。
- 无极底部页面栏隐藏上一页/下一页/页选择器，仅显示类型与逻辑范围。
- 无极文档的 CanvasView 使用 `GlobalKey<CanvasViewState>`；书页不使用该 key，避免翻页过渡期间同一 GlobalKey 同时存在于新旧页。

### 4.4 导出

- `infiniteContentBounds()` 汇总可见图层元素与非空 `page_body` 包围盒，外扩 32 pt；空画布回退 `Rect.fromLTWH(0, 0, 1000, 700)`。
- `renderInfiniteCanvasPng()` 按导出区域设置 1:1 世界坐标、负偏移视口绘制；单边 ≤4096 px、总像素 ≤1200 万，超限等比降采样而非裁切。
- PDF 使用同一 PNG，页面尺寸按内容区域设置；单边超过 14400 pt 时等比缩小 PDF 页面尺寸。书页/书籍导出路径不变。

## 6. 测试与验收

- `./scripts/test_all.sh`：CTest、`flutter analyze`、全部 Flutter/Dart 测试。
- 新增测试覆盖：
  - 无极画布尺寸等于视口且可平移到旧 1600×1200 之外；
  - 平移在 ±100,000 pt 处夹取；
  - 负坐标落笔、负坐标元素命中与拖动；
  - 书页仍按 fit 页矩形（500 pt 页 → 728 px，居中 36 px）；
  - 编辑器“回到原点/适应内容”与书页“适应页面”的互斥入口；
  - 无极文本框在可见视口中心创建；
  - 内容包围盒覆盖负坐标/远坐标，PNG 尺寸与导出区域一致；
  - 空画布导出回退视口。
- 构建：Linux release bundle；Android arm64 release APK。
- 手工：Linux release 启动 8 秒冒烟；不做真机手写/触摸验收（见报告限制）。

## 7. 风险与依赖

- 世界坐标到 100,000 pt 时依赖 Skia 双精度/光栅化精度，本机 widget 测试只覆盖到数千 pt，未做 100k 视觉/性能压测。
- 元素仅做保守跳过，没有 R-tree/分块；数千个远距离元素仍可能增加绘制调用。背景已按视口裁剪，不存在巨型画布分配。
- 导出分辨率上限会降低超大内容区域的像素密度；不裁内容但可能不可读，需后续分块导出/矢量 PDF。
- 旋转图片导出使用保守对角线包围盒，可能增加空白边距，但不会裁切。
- 无极 `page_body` 固定 1600 pt 高度，动态测高仍待实现。
- 不保存无极相机；重开文档按内容重新 fit 或回到原点。
