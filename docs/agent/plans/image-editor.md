# 图片编辑器实现计划

- 计划 ID：PLAN-IMG-001
- 状态：`Completed`
- 日期：2026-10-20
- 对应需求：IMG-004、IMG-005、IMG-006
- 对应决策：D-014、D-019
- 目标版本：1.0.0-alpha.6

## 1. 范围

为图片元素增加非破坏性的裁剪、90° 旋转和水平/垂直翻转，并在画布、PNG 导出、PDF 导出和编辑预览中保持一致。

## 2. 非目标

- 自由角度旋转、透视校正、滤镜、调色。
- 修改原始图片资源。
- 把裁剪结果写回资产。

## 3. 实现

- 图片元素新增参数：
  - `cropLeft` / `cropTop` / `cropRight` / `cropBottom`：归一化 0..1。
  - `rotation`：0/90/180/270。
  - `flipH` / `flipV`：布尔。
- 新增 `image_ops.dart`：参数归一化、最小裁剪面积、统一绘制函数。
- 新增 `image_edit_dialog.dart`：预览、四个裁剪滑杆、左右旋转、水平/垂直翻转、重置/取消/应用。
- 画布与导出路径统一使用 `paintImageElementContent`，避免屏幕与导出结果不一致。
- 点击图片元素打开编辑器；应用后作为一个全局撤销单元保存。

## 4. 验收
