## 1. 产品定位与 1.0 目标

Meowo（喵记）是本地优先、手写与打字并重的跨平台笔记/阅读工作台。第一优先用户是**学生与研究生**；教师、工程师、办公与个人记录用户为次要用户，不得据此扩张 1.0 范围。

1.0 必须完成一条真实闭环：

1. 在资料库创建/导入文档；
2. 在无极或书页画布上用手写笔/手指/鼠标书写、擦除、选择；
3. 插入文本、图片、附件，使用图层；
4. 导入 PDF/EPUB/Markdown，阅读并批注；
5. 搜索、关闭、重开、崩溃恢复；
6. 导出 `.meowo`、PDF、PNG。

**课堂日验收场景**：约 2 小时连续手写、打开 PDF 教材并批注、搜索并重新打开；不丢数据、不崩溃，笔尖到显示 P95 <50 ms（基线设备，60 Hz）。

## 3. 文档模型与页面

### 3.1 三种文档类型，创建后不互转

- **无极文档**：无限画布，逻辑范围约 ±100,000 pt；原点左上；提供回到原点/适应内容；不做小地图或固定页面框。
- **书页文档**：固定纸张的多页文档；最多 500 页；至少保留 1 页。
- **喵书籍**：PDF/EPUB 导入生成；源页为只读固定背景，可叠加批注；允许插入 Meowo 笔记页。

### 3.2 纸张与背景

- 预设 A4/A5/B5/Letter/Legal；自定义 50–2000 mm；创建时选横/竖；内部单位 pt。
- 纸张尺寸/方向创建后不可改；不做页眉、页脚、装订线、裁切线；页码仅在 UI/导出可选。
- 文档级默认背景 + 单页覆盖；空白/横线/点阵/方格四种固定预设；不开放线距/颜色微调。
- 不做单页旋转；不做用户图片页面背景。

### 3.3 页面操作与章节

- 书页：新增、删除、复制当前页、拖动重排、多选页、指定位置插入；最多 500 页；至少 1 页。
- 书页支持手动章节：标题 + 起始页，最多两级；侧边导航；无极不做章节。
- 书籍沿用源 TOC；笔记页可归入章节。
- 书籍源页不可重排/删除；笔记页可插入、删除、重排；导出按当前页序（含笔记页）。

### 3.4 图层与元素

- 每页最多 5 层、至少 1 层；支持新建、删除、重命名、重排、显隐、锁定、透明度、合并；不做混合模式。
- 同一图层内支持上移/下移/置顶/置底；跨层由图层顺序控制。
- 每页最多 1 个 `page_body`；固定在正文区域，不可自由拖动；位于所有图层之下；可删除/重建、隐藏/锁定；可与文本框/图片/笔迹共存。
- 书页 `page_body`：48 pt 正文边距，固定页宽；溢出时编辑内滚动，非编辑显示溢出提示，不自动续排。
- 无极 `page_body`：默认 720 pt 宽，可调宽度；不自由拖动。
- 书籍页除 `page_body` 外允许笔迹、荧光笔、文本框、图片、附件、内部链接；背景只读。
- 书页/书籍页面图层：纸张/源页背景 → 图层从下到上 → 层内元素从后到前。

## 4. 笔迹、选择与输入

### 4.1 笔刷

- 1.0 仅两种：不透明笔 + 荧光笔；不做铅笔纹理、倾斜笔锋、墨水流动。
- 荧光笔使用 multiply 混合与上限透明度，文字保持可读。
- 压力曲线按笔刷保存，可编辑控制点、实时预览、重置；笔与荧光笔分别配置。
- 平台提供 tilt/azimuth 时存储，但 1.0 不渲染倾斜；无倾斜设备完整可用。
- 平滑提供低/标准/高三档，默认标准；文档记录算法与参数版本。
- 线宽以 pt 存储并随画布缩放；跨 DPI 一致。

### 4.2 擦除与选择

- 整笔擦除 + 矢量像素擦除；默认当前图层，可切换所有可见图层。
- 像素擦除通过切分矢量笔迹实现，保留压力/笔刷属性；一次擦除手势 = 一个撤销单元；撤销恢复原笔迹。
- 套索：自由套索 + 矩形；默认相交即选；支持加选/减选。
- 选中对象支持移动、等比/非等比缩放、自由旋转、删除；不做 90° 吸附、翻转、编组/解组、对齐/分布。
- 选择范围：当前页所有可见未锁定图层；隐藏/锁定层不可选；不支持跨页框选；可复制到另一页并保留相对位置。

### 4.3 输入矩阵

| 设备 | 默认 |
|---|---|
| 手机 | 单指执行当前工具；双指平移/缩放 |
| 平板/桌面 | 笔绘制；单指平移；双指平移/缩放 |
| 所有平台 | 提供“手指可绘制”开关；双指始终优先 |
| 掌拒 | 自动 + Auto/Pen only/Finger can draw 三档；检测到笔时触摸仅平移缩放 |

- Android 原生 `MotionEvent`/`InputDevice`；Windows `WM_POINTER`/Windows Ink；Linux libinput + Wayland tablet protocol。统一归一化为一个笔事件模型。
- 笔尾/橡皮键 = 擦除；侧键可配置为临时擦除或套索；不做双击笔身映射。
- 悬停预览可用则用；橡皮光标始终显示；预测线可选且不持久化。
- 单指/双指/鼠标快捷键见 `04`，但以本节输入矩阵为准。

### 4.4 撤销

- 统一画布命令栈覆盖笔迹、对象变换、图层、页面增删/重排；文本局部历史，提交后成为**一个**全局撤销单元。
- 默认 100 步/文档；全应用 256 MB 历史预算，所有打开标签共享；超限丢最旧历史。
- 历史不跨重启保存。

## 5. 文本

- Markdown 为唯一事实源；**源码编辑 + 渲染预览**，不做 WYSIWYG。桌面并排，移动端切换。
- 范围：CommonMark + GFM 表格/任务列表/删除线/自动链接；不承诺脚注、定义列表、front matter、TOC。
- 数学：KaTeX 兼容子集，`$...$`、`$$...$$`、`\(...\)`、`\[...\]`；不支持自定义宏/mhchem/完整 LaTeX；错误显示可编辑占位。
- HTML：仅无属性白名单标签（`<br>`、`<sub>`、`<sup>` 等）；其余按纯文本；禁止脚本、事件属性、内联样式注入、远程资源。
- 链接：HTTP(S)、mailto、内部 `meowo://asset/...`、文档内锚点；外链需确认；禁止 `file://`；远程图片不自动加载。
- 代码块基础高亮（C/C++、Python、JS/TS、JSON、Shell 等）；宽表格横向滚动；任务列表勾选回写 Markdown。
- Markdown 图片：基础内联图 + alt + 缺失占位；不支持宽高/对齐/图注。
- 文本框：默认自动高度，可切固定高度；固定高度溢出时编辑内滚动 + 非编辑提示，绝不静默裁切；支持透明度/锁定；不支持旋转。
- 排版：字号、行高、颜色、对齐、粗斜体等基础能力；不支持自定义字体、字距、首行缩进、文字背景。
- 横排；基础 CJK 换行与简易禁则；不做竖排/RTL/严格标点挤压。
- IME 原生候选窗；组合未提交不写历史；粘贴富文本降为纯文本；不做富文本转 Markdown。
- 文档内查找 + 字数统计；不做替换、拼写检查、自动更正。
- 渲染文本可选可复制；所有文本元素进搜索索引；公式提供 TeX/可读替代；表格保留表头语义；代码按纯文本朗读。

### Markdown 文件导入

- 1.0 支持 `.md` 导入；生成**可编辑的书页文档**，正文为 `page_body`，按分页规则切开；不生成只读书籍，不自动重排。
- 相对路径图片复制并内嵌；缺失图片显示占位；1.0 不回写 `.md`。
- 超长段落/分页规则仍是发布前需手工确认项。

## 6. 图片、附件与资源

### 图片

- 仅 PNG/JPEG/WebP；HEIC/HEIF/AVIF/GIF/SVG 明确拒绝并提示转换；不自动转码。
- 单图 ≤50 MP、≤256 MB；先应用 EXIF 方向，再剥离 GPS/设备隐私元数据；保留 alpha；色彩归一化到 sRGB。
- 内置编辑器：裁剪 + 90° 旋转 + 水平/垂直翻转；非破坏参数，可重编辑/恢复原图。
- 图片是普通元素，支持自由旋转、非等比缩放、透明度、锁定；不做用户图片页面背景。

### 附件

- 任意文件类型可嵌入 `.meowo`；单附件 ≤512 MiB（SQLite BLOB 安全边界内）；单文档建议 ≤16 GiB；>100 MiB 警告。
- 画布显示自动 MIME 图标 + 文件名；文本中用超链接；不做自定义图标。
- 附件面板：图标/文件名/大小/类型；**没有应用内预览**；一律用系统应用打开；缺失关联或损坏显示明确错误。
- 不执行脚本/可执行文件；不支持加密附件/ZIP；提示用户先解密/解压。
- 引用保护：有引用时禁止删除并显示引用位置；无强制删除；无引用后可删；孤儿资源在保存/压缩时 GC。
- 复制文档/跨文档粘贴深拷贝资源，新 ID，重写内部链接，按内容哈希在目标内去重。
- 桌面支持拖放导入、剪贴板文件粘贴、批量导入；导入冲突/命名/回滚规则需实现并测试。

## 7. 书籍（PDF/EPUB）

- PDF/EPUB 统一 MuPDF；EPUB 导入时生成**固定页 PDF 快照**，保留原 EPUB；不提供可重排阅读。
- EPUB 快照保留文本层（源有文本时），支持搜索/选择/复制；扫描 PDF 不做 OCR。
- 密码保护 PDF 可打开并批注；不做表单、签名、嵌入附件、3D/视频、JavaScript。
- 尊重 PDF 权限标志（复制/打印/导出）；受限操作明确提示。
- 支持 PDF 大纲、内部页链接、外链确认、文本选择/复制、全文搜索并高亮。
- 书籍页保留源页实际 crop box 与 rotation；允许混合页尺寸；背景不叠加纸张纹理。
- 非加密 PDF 页使用 MuPDF 按需 SVG + flutter_svg 真矢量背景（2026-10-20）；原 PDF 保留，PNG 快照作为加密/EPUB/失败页回退与缩略图来源。导出的 PDF/PNG 仍为位图。
- 大 PDF 按需渲染当前页 + 邻近页 LRU；首页优先；缩略图懒加载、低分辨率、异步、不阻塞打开；矢量页同样按当前页 ±1 后台解析。
- 批注：笔迹、荧光笔、文本框、图片、附件、内部链接，按图层；无 `page_body`；不做书签/便签。
- 保存封面、标题/作者、源 TOC、当前阅读页；不保存阅读进度百分比/书签/跨设备同步。
- 批注锚定固定快照页坐标；缩放/设备变化不漂移；不承诺文本锚点/重排。
- DRM EPUB（Adobe/Apple/Kobo 等）不支持；明确提示用户使用无 DRM 文件，不规避。
- EPUB 静态：禁用脚本/网络/音频/视频/交互/远程字体图片；缺失远程资源占位。
- 笔记页允许插入源页之间；PDF 导出默认压平可见批注；不支持替换源文件（新建文档）。

## 8. 资料库、搜索、存储与恢复

### 资料库

- 单用户、单资料库；桌面默认系统应用数据目录，可自选资料库路径；不做多库/便携模式。
- 虚拟文件夹最多 3 级；每文档一个文件夹；移动只改归属，不移动文件；未分类归“全部/未分类”。
- 收藏、最近打开、标题/修改/创建时间升降序；不做标签、颜色、置顶、手动拖拽排序、智能筛选。
- 删除进回收站 30 天；可手动清空；自动清理提示；恢复保留文件夹/收藏/阅读位置；文件夹不存在则回未分类。
- 缩略图异步生成；封面默认第 1 页，可手动更换；256 MB LRU 缓存，可重建；失败占位，不阻塞打开。

### 搜索

- 标题、文本元素、书籍可提取文本层、附件文件名。
- **不搜索手写，不做 OCR**；帮助/宣传明确说明。
- 中文：SQLite FTS5 trigram + 1–2 字 LIKE/前缀回退；不捆绑中文词典；索引为可重建本地缓存；结果显示上下文/高亮。
- 文档内查找 + 字数统计；不做替换。

### 存储

- `.meowo` 单文件 SQLite，WAL、FULL sync、外键、application_id、user_version。
- Android 活动资料库必须在应用私有目录；SAF 仅导入/导出。桌面可自选目录；云盘/同步文件夹不作为活动库。
- 自动保存：1 秒 debounce，最长 5 秒；切页/切工具/后台/关闭时提交；UI 显示保存中/已保存/失败；失败绝不显示成功；关闭等待保存并处理失败。
- 崩溃恢复：最后成功事务 + 文本草稿；未提交笔迹最多丢一个 debounce 窗口；显示恢复横幅并保留恢复副本。
- 同一 `.meowo` 第二实例/另一台机器：只读视图 + 横幅，可另存副本；不承诺网络盘并发写。
- **Alpha.5 偏差**：当前为工作区级独占锁，第二个实例直接拒绝（D-032）；只读视图/另存副本仍未实现。
- 导入 `.meowo` 永远复制并分配新 ID；同 ID 冲突提示“导入副本/取消”，不覆盖；保留源文件。
- 导出默认文件名 = 清理后的标题 + 日期；总弹保存位置；目标存在必须显式覆盖确认。
- 迁移旧版 `.meowo`：先自动备份，可回滚；不承诺降级。

## 9. 导出、打印与更新

- 1.0 导出：`.meowo`、PDF、PNG 压缩包、选中页 PNG；不做系统打印。
- 导出页面范围、页码仍未完全闭合（OQ-008）；不得静默裁切内容。
- 无极画布导出（2026-10-20 实现）：PNG/PDF 使用可见内容包围盒 + 32 pt 留白，不使用旧的 1600×1200 页面；空画布回退到原点附近 1000×700 pt；隐藏图层不导出。输出图像单边 ≤4096 px、总像素约 ≤1200 万，超限时等比降采样；PDF 页面单边 ≤14400 pt。旋转图片使用保守包围盒避免裁切。
- 更新：仅手动“检查更新”，打开 GitHub Releases；不自动下载/安装；deb/rpm 交给包管理器。

## 10. 界面、交互与无障碍

- Material 3；暖白纸张、墨黑文字、琥珀/橙强调色；系统字体；Material Symbols Rounded；克制动效。
- UI 语言：简体中文 + English；不做繁体/RTL/竖排；日期/数字跟随系统 locale。
- 单窗口 + 标签页；同一文档仅一个编辑标签；再次打开聚焦已有标签；重启恢复标签，不恢复未保存临时状态。
- 手机完整编辑（横竖屏）；桌面/平板侧栏工具栏，手机底栏；不做自定义工具栏/Radial menu/左手模式/UI 缩放/超大触控目标。
- 翻页：缩略图侧栏 + 底部页码/跳转 + 上一页/下一页 + 键盘翻页；无全屏/专注模式。
- 深色模式只影响 UI；纸张保持白/米白/浅灰；图像不反色；不做护眼/棕褐模式。
- 首启 2–3 屏引导 + 可删除示例文档；普通错误 Snackbar + Retry；决策/数据风险对话框；字段校验内联。
- 无障碍：**验收仅自动化扫描**；不再承诺完整屏幕阅读器/纯键盘可用；保留基础字体缩放（至少 200% 不破版）、高对比度、减少动画、色盲友好 UI；不强制重着色用户笔迹；画布不做逐笔朗读。

## 11. 性能与质量门禁

- 笔尖到显示 P95 <50 ms（基线设备，60 Hz；用真实笔 + 高帧率相机/触控日志）。
- 每页 20,000 笔迹、单文档 500 页可打开/编辑；单附件 512 MiB；单文档建议 ≤16 GiB。
- 冷启动 <3 s；标准文档打开 <2 s；翻页 P95 <150 ms。
- Android 峰值内存 <1 GB；桌面峰值 <2 GB；Android APK <150 MB；桌面安装包 <200 MB。
- Phase 0 实测后门槛**只能收紧，不能放宽**。
- 测试：C++ 行覆盖 ≥80%，关键模块分支 ≥85%；Dart ≥70%；关键路径集成测试；笔/PDF/EPUB/保存恢复需真机人工验收；每个 S0/S1 修复加回归测试。覆盖率不等于正确性。
- 基础 fuzz + 定向安全用例：损坏 `.meowo`、恶意 PDF/EPUB、超大图片、路径穿越、HTML 注入；1.0 无第三方安全审计，发布说明披露残余风险。
- 发布阻断：任何未解决的 S0 数据丢失/损坏；发布否决权在负责人。
